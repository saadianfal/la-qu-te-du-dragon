🐉 La Quête du Dragon
Présentation
La Quête du Dragon est un jeu de rôle développé en Python. Le joueur évolue dans un univers fantastique où ses choix déterminent le déroulement de son aventure.
Objectif
Explorer un monde imaginaire, relever des défis et accomplir une quête pour atteindre son objectif.
Technologies utilisées
Python 3
Lancement du jeu
Exécuter le fichier jeuderole.py depuis le terminal :
python3 jeuderole.py
Auteur
Projet personnel réalisé dans le cadre de mon apprentissage de la programmation Python.
